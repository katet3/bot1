# verification_engine

Verifier.verify(method) строит CFG и запускает четыре структурных правила. Это не полная Java Card verification. Контекст индексирует только рёбра между существующими блоками; исходные рёбра сохраняются для диагностики. Ошибки объединяются в плоский список.
