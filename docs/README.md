# Документация разработчика cap2soot

Редакция: **29 октября 2026 года**. Документы описывают рабочую копию проекта после
обновления `bot1_javacard_execution_update.zip`, включая исполнение `name1.cap`.
Базовый commit: `071753ddf57b4182ee94eebd49147a2b84a19a7b`; последующие изменения
входят в рассматриваемый снимок, поэтому один этот commit не воспроизводит его.

Начните с [полного руководства по проекту](PROJECT.md). Для изменения конкретного
этапа используйте руководство подсистемы и [каталог всех 107 Python-модулей](SOURCE_MAP.md).
Каталог включает вспомогательные файлы, тесты и пустые заготовки; наличие файла
само по себе не означает, что соответствующая возможность реализована.

Документация ведётся в Markdown рядом с кодом. Относительные ссылки рассчитаны
на размещение каталога `docs/` в корне проекта. Архив документации распаковывается
туда же. Общий документ можно читать самостоятельно; руководства модулей раскрывают
детали реализации и порядок изменений.

Новые руководства являются актуальным описанием. Файлы `UPDATE_*.md` и старые
журналы тестов сохраняются как история отдельных этапов. Их формулировки о будущем
развитии не следует воспринимать как статус текущей рабочей копии.
